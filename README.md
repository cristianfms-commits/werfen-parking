# Werfen Parking

App web instalable (PWA) para registrar tickets de parqueadero en formato chat: foto del ticket, número, carro/moto y quién lo recibió.
Genera el Excel diario (con fotos) al cierre de las 8:00 p. m., lo corrido del mes, el consolidado a la fecha, un ZIP con todos los diarios y copias de respaldo.

- No requiere cuenta ni servidor: los datos se guardan solo en el teléfono de quien la usa (IndexedDB).
- Funciona sin internet una vez abierta.
- Werfen Colombia & Latam Distribution.
